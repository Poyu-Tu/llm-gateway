- **練習本對照：** 整體：`app/main.py` 的 `chat_endpoint()`

先講結論【#】。我的 Gateway 每次呼叫都在回答三個問題：誰在用？花了多少？送出去的有沒有個資？接下來每一頁，都是在回答其中一題。

### 第 4 頁｜想解決的問題

- **配給：** 25 秒
- **練習本對照：** —

為什麼要問這三題？想像公司開放兩百個人用 AI【#】，月底帳單來了，你知道是誰花的嗎？多半不知道【#】。有人寫錯一個迴圈，一個晚上燒光預算【#】；有人把客戶資料貼進去，事後查不到。這三件事，剛好就是那三個問題。

### 第 5 頁｜解決前後

- **畫面上：** 節費、個資、額度三列
- **配給：** 16 秒
- **練習本對照：** —

我的做法是這樣：以前是月底才知道，現在是每一次送出前就知道。畫面上這個 20 倍是單價差，實際能省多少，等一下用實測數字講。

### 第 6 頁｜解法提綱｜三道關卡

- **畫面上：** 員工 → 閘道 → 模型；管人、管錢、管資料
- **配給：** 19 秒
- **練習本對照：** 管人 `app/auth.py`；管錢 `app/router.py`、`app/quota.py`；管資料 `app/audit.py`

那怎麼做到「送出前就知道」？就像大樓只有一條總水管，我幫每一戶裝水表和限流閥。每次呼叫先過三關【#】：管人，知道是誰【#】；管錢，知道花多少【#】；管資料，知道送出什麼。

### 第 7 頁｜解法提綱｜雲端架構

- **畫面上：** VPC 每日層、長期層、OpenAI、GitHub Actions
- **配給：** 67 秒
- **練習本對照：** 設定檔分頁：Terraform 兩層

我將三道關卡放到 AWS 上長這樣，我照著箭頭走一次請求【#】。員工從 ALB 進來，它是這棟大樓唯一的大門，只放我的 IP【#】。請求進到 Gateway，它跑在 Fargate 上，就是我租的那間空房，放在 Private Subnet、沒有 Public IP，外面找不到它【#】。Gateway 要問 OpenAI，只能從 NAT 這一個後門出去，門口有 DNS Firewall，只放行名單上的網域【#】。答案回來之後，Gateway 先把這筆帳丟進 SQS，確認收到了，才把答案交給員工【#】。Lambda 在背後把帳記進 DynamoDB【#】。這一整圈用 Terraform 建起來，換版和拆除都交給 GitHub Actions；外面灰色的是長期層，帳本、資料表、角色都在這裡，平常不拆【#】。等一下講到出口、拆除、記帳，都會回到這張圖。

### 第 8 頁｜解法提綱｜一次呼叫發生什麼事

- **畫面上：** 11 步流程，紅色是擋下時回的代碼
- **配給：** 34 秒
- **練習本對照：** `chat_endpoint()` 從上讀到下

進到 Gateway 裡面，一次呼叫會走 11 步。上排 6 步是門禁：Key 錯了回 401、額度用完回 429，連資料庫讀不到時也擋下來，不放行【#】。任何一步擋下，都還沒碰到模型，一毛錢都沒花【#】。第 4 步之後，Gateway 送出去的、寫進紀錄的，都是遮罩後的內容【#】。下排 5 步才真的做事。門禁在前，花錢在後。

### 第 9 頁｜解法提綱｜三件事、兩層、一鍵

- **畫面上：** 三個原則、長期層與每日層、一鍵拆除

當我們要買一瓶飲料，不會叫整台貨車送吧【#】。左邊翻一句英文，交給便宜模型，花 7 micro-USD，也就是百萬分之七美元【#】；右邊請 AI 設計一個系統，才交給強模型，花 1,438【#】，兩顆單價差 20 倍【#】。判斷規則很簡單，只看兩件事：超過 300 字，或出現關鍵字。

### 第 12 頁｜省更多很簡單，答對比較難

- **畫面上：** 25.3%；兩個總額；不選 54% 的說明（10/31 改：28.7% 裡 24.2% 來自同一題）；雲端 Grafana

- **練習本對照：** `scripts/routing_eval.py`；`app/metrics.py`

那實際省多少【#】？20 題實測，省了 25.3%【#】。省更多很簡單，門檻放寬就能到 54%，但我沒選。因為多出來的 28.7% 裡，有 24.2% 來自最難的那一題，等於一個樣本撐起整個數字；而且把難題送錯模型，代價比多花一點錢大得多【#】。所以我選 25.3%，不選 54%。右邊的 Grafana，後面 demo 裡再看。

### 第 13 頁｜技術實踐｜節費：備援

### 第 18 頁｜看不到的地方 ①｜先拆 LiteLLM：兩個靜默錯誤

### 第 24 頁｜看不到的地方 ③｜沒有長期金鑰

- **配給：** 32 秒
- **練習本對照：** `app/openai_auth.py` 的 `get_aws_identity_token()`

這整套裡，repo 沒有任何 key【#】。GitHub 要動 AWS，不是拿 key，是憑身分換一張一小時就過期的通行證，而且只有 main 換得到【#】；別的分支在 GitHub 這層就被擋住【#】。Gateway 呼叫 OpenAI 也一樣，用 AWS 的 IAM role 向 STS 要證明，再換 OpenAI 的通行證。沒有 key，就沒有 key 可以外流。
