**第 15 頁重截的原因與做法（已完成，PR #14）：** `scripts/routing_eval.py` 把 R2、R3 都印成「現在的設定檔…」，看的人分不出哪個是採用的。改法：第 115、116 行的標籤改成「R2 採用：現在的規則（300 字＋關鍵字，10/13 定案）」「R3 對照：字數門檻放寬到 500」，重跑 `uv run python -m scripts.routing_eval`（只讀 `docs/logs/m3-step7-routing-run.json`，不呼叫模型、不用金鑰），重截 S06 右半、重錄 m3-s06。改標籤要經 PR，練習本「程式對照」的 `routing_eval.py` 一節補一行。

**推算怎麼來的（第 17 頁）：** 用這 20 題算出來的平均數：一題簡單題用強模型約 1,016 micro-USD、用便宜模型約 51；一題複雜題約 6,074。把簡單題從 13 題（65%）推到 16 題（80%）、18 題（90%），其餘是複雜題，而且假設每一題都分對（完全分流），得到約 38%、約 57%。65% 那一格的 25.3% 是「採用的規則」的實測；80%、90% 是「完全分流」的推算，所以標「推算・完全分流」。問起來就這樣講，不要說成實測。

**第 16 頁的用詞（本人定）：** 「多省的 29%」照本人的話寫；嚴格說是 29 個百分點（54.5 − 25.3），口頭講的時候可以補一句。
