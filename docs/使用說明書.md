# LLM Gateway 使用說明書

> 給自己看的操作手冊：怎麼把 Gateway、Console、Prometheus、Grafana 打開、怎麼關掉，以及常撞到的問題。
> 一律在 repo 最上層（`C:\Users\tupoy\llm-gateway`）的 PowerShell 執行。帳號 ID、IP、API Key 不寫進任何紀錄、不錄進影片。
> 最後更新：2026-10-27（M6 上雲、M7 完成後）

---

## 0. 先看這張表：三個網頁、要不要登入

| 網頁 | 本機網址 | 雲端網址 | 要登入嗎 | 看什麼 |
|---|---|---|---|---|
| **Console** | `http://127.0.0.1:8000/` | `http://<ALB 網址>/` | 貼 **API Key** | 問問題、看分給哪顆模型、花多少、剩多少額度 |
| **Grafana** | `http://127.0.0.1:3000` | （一樣是本機這個） | **不用**，打開就是儀表板（只能看） | 每個人、每顆模型花多少、被擋幾次 |
| **Prometheus** | `http://127.0.0.1:9090` | （一樣是本機這個） | **不用** | `/targets` 頁看「抄表」有沒有成功 |

**一句話記住：** Grafana 和 Prometheus 永遠在你自己的電腦上跑，**不用帳密**；只有 Console 要 Key。
複雜的不是「登入」，而是雲端那一串**安全準備**（短期憑證、只放行一個 IP、Key 只顯示一次）。下面照順序打就好。

**比喻：** Console 是銀行櫃台（要拿存摺＝Key 才能辦事）；Prometheus 是每 15 秒去抄一次水錶的抄表員；Grafana 是把抄來的數字畫成圖的帳單。抄表員和帳單都在你家，只有櫃台在外面。

## 1. 本機模式（不花 AWS 的錢；問問題會花一點 OpenAI 的錢）

### 1-1 打開

```
docker compose up -d
$env:CHARGE_QUEUE_URL = "disabled"
uv run --env-file .env uvicorn app.main:app
```

- 第 1 行：開本機的 DynamoDB（練習場，資料只放記憶體）
- 第 2 行：`.env` 裡沒有這一行，不設的話 Gateway 一啟動就 `KeyError: 'CHARGE_QUEUE_URL'`
- 第 3 行：起 Gateway；看到 `Uvicorn running on http://127.0.0.1:8000` 就好了，**這個分頁開著別關**

### 1-2 發 Key（開第二個分頁）

```
uv run --env-file .env python -m scripts.seed
```

- 印出 `alice`、`bob`、`carol` 三把 Key，**只會出現這一次**
- 要用的複製到記事本（不要存檔），然後打 `cls` 清掉畫面
- 三個人的月額度：alice 1,000 micro-USD（約一題強模型就用完）、bob 1,000,000、carol 10,000
- 本機資料庫是記憶體：**電腦重開或容器重開後要重新發 Key**

### 1-3 Console

Chrome 打開 `http://127.0.0.1:8000/` → 貼 Key → 登入。換人：右上角「登出」。

### 1-4 Prometheus ＋ Grafana

```
docker compose -f monitoring/compose.yaml up -d
```

- `http://127.0.0.1:9090/targets`：`gateway-local` 要是 **UP**
- `http://127.0.0.1:3000`：直接是 LLM Gateway 儀表板；右上角時間選「Last 1 hour」

### 1-5 跑 agent（M7）

```
uv run python -m scripts.agent_demo
```

- 問 `API Key:` 時貼 Key（畫面不顯示，正常）
- 加 `--max-steps 0 --budget 0`：拿掉 agent 自己的兩道煞車，只靠 Gateway 的額度擋

### 1-6 關掉

- Gateway 那個分頁按 `Ctrl+C`
- `docker compose down`（DynamoDB）、`docker compose -f monitoring/compose.yaml down`（監控）

## 2. 雲端模式（開始計費，做完一定要拆）

**一定要在家裡網路或手機熱點做，不要用咖啡店、公司的公共 Wi-Fi**：ALB 是 HTTP、只放行一個 IP；公共網路整間共用一個 IP（門禁失效），而且開放 Wi-Fi 上送的 Key 和通行證可能被旁邊的人攔到。

### 2-1 登入 AWS（開一個新分頁，之後雲端的事都在這個分頁做）

```
aws login
aws configure export-credentials --format powershell | iex
aws sts get-caller-identity
```

- 第 2 行把臨時通行證抄進這個分頁，給 **Terraform 和 Python** 用；**大約 15 分鐘就過期**
- 只用 `aws` 指令的話不需要第 2 行（CLI 會自己換新）
- 這段畫面有帳號 ID，**不要錄影**

### 2-2 建每日層

```
$env:TF_VAR_admin_cidr = "$((irm checkip.amazonaws.com).Trim())/32"
$env:TF_VAR_image_tag = "<ECR 裡已經有的映像標籤，例如 main 最新 commit 前 7 碼>"
terraform -chdir=infra/daily plan -no-color | sls source_code_hash
terraform -chdir=infra/daily apply
```

- `plan` 那行要看到 Worker 的指紋跟上次一樣（不一樣的話 CD 換版時守門會擋）
- `apply` 前看 `Plan: 42 to add` 才打 `yes`；**從這一刻開始計費**
- 一律用 `-chdir=infra/daily`；在 repo 最上層直接 `terraform plan` 會說 `No configuration files`

### 2-3 GitHub 的 `ADMIN_CIDR`

在同一個分頁印出剛剛的值，貼到 GitHub → Settings → Environments → **deploy** → `ADMIN_CIDR`：

```
$env:TF_VAR_admin_cidr
```

跟 apply 用的不一樣的話，CD 會想改安全群組 → 守門擋下。

### 2-4 CD 換版

GitHub → Actions → **deploy** → Run workflow（分支 `main`）。約 3 分鐘，綠燈 = 守門放行、換版、等到穩定。

### 2-5 雲端發 Key

```
aws configure export-credentials --format powershell | iex
$env:DYNAMODB_TARGET = "aws"
uv run python -m scripts.disable_key --user alice
uv run python -m scripts.disable_key --user bob
uv run python -m scripts.disable_key --user carol
uv run python -m scripts.seed
Remove-Item Env:DYNAMODB_TARGET
```

- 先停舊的再發新的：`seed` 不會讓舊 Key 失效
- **`seed` 不會把本月已花歸零**：雲端的額度帳在長期層，同一個月內用完就是用完（10 月 alice 已用完）。要示範「被擋」選本月還沒用完的人
- 最後一行一定要打：不清掉的話，之後在這個分頁跑測試會連到雲端資料庫

### 2-6 雲端 Console

```
$alb = terraform -chdir=infra/daily output -raw alb_dns_name
"http://$alb/"
```

把印出的網址貼到 Chrome。Chrome 顯示「不安全」是因為 HTTP（決策書刻意接受，前提是只有你的 IP 進得來）。

### 2-7 讓本機的 Grafana 看雲端

ALB 的網址每次建每日層都會變，所以兩個檔都要重寫（都在 `monitoring/secrets/`，不進 Git）：

```
'[{"targets": ["' + $alb + ':80"], "labels": {"env": "cloud"}}]' | Set-Content -Encoding ascii monitoring\secrets\cloud-targets.json
$tok = aws ssm get-parameter --name /llm-gateway/metrics-token --with-decryption --query Parameter.Value --output text
Set-Content -NoNewline -Encoding ascii monitoring\secrets\metrics-token $tok
docker compose -f monitoring/compose.yaml up -d
```

- 通行證檔**一定要** `-NoNewline -Encoding ascii`：多一個看不見的字元，ALB 就當成錯的 → 403
- `http://127.0.0.1:9090/targets` 的 `gateway-cloud` 是 UP 就成功；Grafana 左上「環境」選 `cloud`

### 2-8 拆光（不管做到哪裡，睡前一定要做）

1. GitHub → Actions → **destroy** → Run workflow（約 5 分鐘）
2. 直接問 AWS 還有沒有在收錢的：
   ```
   aws ec2 describe-nat-gateways --filter Name=state,Values=available --query "NatGateways[].NatGatewayId"
   aws elbv2 describe-load-balancers --query "LoadBalancers[].LoadBalancerName"
   aws ecs list-services --cluster llm-gateway
   ```
   三個都是 `[]`（或叢集不存在）才算拆乾淨
3. GitHub 的 `ADMIN_CIDR` 改回 `192.0.2.1/32`（家裡 IP 不要一直留在 GitHub）

## 3. 常撞到的問題

| 看到什麼 | 原因 | 怎麼辦 |
|---|---|---|
| `ExpiredToken`、`credentials are still expired` | `export-credentials` 抄進來的通行證過期了（約 15 分鐘），重新 `aws login` 也沒用，因為 CLI 先讀環境變數 | `aws login` → `Remove-Item Env:AWS_*` → 需要 Terraform／Python 時再 `export-credentials` |
| `$env:...` 印出來是空的 | 環境變數只存在**設定它的那個分頁** | 回到原本那個分頁打 |
| `KeyError: 'CHARGE_QUEUE_URL'` | `.env` 沒這行 | `$env:CHARGE_QUEUE_URL = "disabled"` |
| `WinError 10048`（8000 埠被佔） | 上一次的 Gateway 還開著，或 `--profile gateway` 的容器還在 | 關掉舊的再開 |
| Console 一登入就說額度用完 | 這個人本月已經用完；`seed` 不歸零 | 換一個本月沒用過的人 |
| Prometheus 的 `gateway-local` 是 DOWN | 本機 Gateway 沒開 | 只看雲端時這是正常的 |
| `gateway-cloud` 是 DOWN、錯誤 403 | 通行證檔有多餘字元，或換了網路 IP 變了 | 照 2-7 重寫；換網路要重跑 2-2 的 IP 與 apply |
| `/metrics` 帶對通行證還是 403 | 網址多了結尾斜線 `/metrics/` | 這是刻意擋的「繞路」，網址不要加斜線 |
| `terraform plan` 說 `No configuration files` | 在 repo 最上層直接跑 | 加 `-chdir=infra/daily` |

## 4. 錄影與截圖的規矩

- Key 只在 `seed` 當下出現一次；錄影前 `cls`、記事本不要入鏡
- 錄終端機前把提示字元改短（只影響這個視窗）：`function prompt { "PS> " }`
- 帳號 ID、IP 不入鏡；ALB 的網址可以（它不是 IP）
- 錄影放 `Videos\llm-gateway-mp4\`，檔名 `m<關卡>-<主題>.mp4`
