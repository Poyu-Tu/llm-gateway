# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub instead:
**Security** tab → **Report a vulnerability**
(<https://github.com/Poyu-Tu/llm-gateway/security/advisories/new>).

Please include:

- the file and commit you looked at
- the steps to reproduce it
- what an attacker could do with it

This is a personal capstone project maintained by one person.
I will try to reply within 7 days. There is no bug bounty.

## Scope

- In scope: the code in this repository (`app/`, `scripts/`, `.github/workflows/`, `Dockerfile`, `compose.yaml`).
- Out of scope: the OpenAI API and AWS services themselves.

Only the `main` branch is supported.
